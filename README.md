# Birthday Invitation Generator

A simple Java console application that creates personalized birthday invitations based on user input.

## Features

- Accepts the birthday person's name
- Accepts date, time, and venue
- Accepts a personalized message
- Generates a formatted birthday invitation
- Demonstrates basic Java programming concepts

## Concepts Used

- Java `Scanner`
- Variables and data types
- String handling
- User input
- `System.out.println()`
- Basic program structure

## How to Run

### 1. Compile the program

```bash
javac BirthdayInvitation.java
```

### 2. Run the program

```bash
java BirthdayInvitation
```
